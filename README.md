# Landing Page

Project name:
Landing Page — Portfolio (based on BIKE New Version Figma design)
Description:
Portfolio landing page built from the BIKE New Version Figma template. Includes hero section, products section, contact form and fully responsive layout. Animations on scroll implemented with Intersection Observer API.

Technologies:

HTML5
CSS3 / SASS
JavaScript (ES6)
Parcel (build tool)
Intersection Observer API (scroll animations)
<picture>/<source> (responsive image optimization)
GitHub Pages (hosting)
favicon (.ico)

Demo & Design

Live demo: https://JorJio-svg.github.io/layout_landing-page/
Figma design: https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f&t=m61EfMO48ZPaJaPa-0

How to run locally

git clone <repo-url>
cd repo
npm install
npm start


Notes

Images optimized (WebP and fallbacks).
Smooth scrolling and accessible keyboard focus support.
Check mobile layout to avoid horizontal scroll.
